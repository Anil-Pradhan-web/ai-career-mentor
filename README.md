## 🧭 **1. What is AI CAREER MENTOR?**

**CAREERMENTOR.AI** is an open-source, production-grade **Autonomous Career Operating System** 🤖 designed to eliminate fragmentation across developer hiring. Instead of forcing candidates to juggle 5–7 disconnected paid subscriptions ($250–$500/month for Jobscan, Teal, LeetCode, Levels.fyi, and Interviewing.io), CareerMentor unifies the entire career journey through **5 dedicated, decoupled autonomous AI agents**:

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                     CAREERMENTOR.AI SYSTEM SUITE                       │
 └───────┬──────────────┬──────────────┬──────────────┬───────────────────┘
         │              │              │              │
         ▼              ▼              ▼              ▼
  ┌─────────────┐┌─────────────┐┌─────────────┐┌─────────────┐┌────────────────────────┐
  │  AGENT 1:   ││  AGENT 2:   ││  AGENT 3:   ││  AGENT 4:   ││       AGENT 5:         │
  │ ATS Resume  ││ 8-Week RAG  ││ Live Market ││  LinkedIn   ││ Live Voice & Coding    │
  │ Diagnostic  ││   Roadmap   ││Intelligence ││  Optimizer  ││   Mock Interviewer     │
  └─────────────┘└─────────────┘└─────────────┘└─────────────┘└────────────────────────┘
     (1 use/day)  (1 use/3 days)  (2 uses/day)   (2 uses/day)      (1 session/5 days)
```

1. **ATS Resume Diagnostic Agent:** Deterministic parsing, 120+ skill dictionary match, ChromaDB RAG against role standards, and quantitative bullet rewriting.
2. **8-Week Personalized Learning Roadmap Agent:** Gap-driven, progressive syllabus with curated GitHub repositories and YouTube tutorials.
3. **Live Labor Market Intelligence Agent:** Real-time web scraping via DuckDuckGo, salary percentiles (25th/50th/75th/90th), and trending framework demands.
4. **Executive LinkedIn Strategy Agent:** High-conversion recruiter headline formulas, STAR narrative About stories, and top 5 skill positioning.
5. **Streaming Voice & Coding Interview Copilot:** Low-latency WebSockets, background Edge-TTS audio pipelining, in-browser Monaco Editor, 160+ curated tech companies across 12 sectors, and multi-phase guided technical drills with 360° scorecards.

<a id="the-5-autonomous-ai-agents"></a>
## 🤖 **4. The 5 Autonomous AI Agents**

---

### 📄 **Agent 1 — ATS Resume Diagnostic & Scorer**
> **Endpoint**: `POST /resume/analyze` · **Protocol**: REST · **Rate Limit**: 1 use / 24 hours (24h cooldown)

**How It Works:**
1. **Multi-Format Extraction:** PyMuPDF extracts raw text from PDF uploads, normalized to prevent token explosion.
2. **Deterministic Experience Math:** Regular expressions calculate real employment dates, accounting for overlapping tenures and gap detection.
3. **120+ Skill Dictionary:** Audits required vs. missing competencies across languages, frameworks, databases, cloud, and tools.
4. **ChromaDB Vector RAG:** Queries curated industry standards for the target role to compute contextual alignment.
5. **Actionable Bullet Rewriter:** Emits instant bullet transformations applying Google's **XYZ formula** (*"Accomplished [X], as measured by [Y], by doing [Z]"*).

---

### 🗺️ **Agent 2 — Dynamic 8-Week Personalized Learning Roadmap**
> **Endpoint**: `POST /roadmap/generate` · **Protocol**: REST · **Rate Limit**: 1 use / 72 hours (3-day cooldown)

**How It Works:**
1. **Gap Extraction:** Ingests candidate's verified skill deficiencies from the ATS diagnostic or target role requirements.
2. **2-Stage Generation Engine:**
   - *Phase 1 (Structure):* LLM generates a structured 8-week syllabus with milestones, core topics, and estimated hours.
   - *Phase 2 (Enrichment):* Batch enriches each week with curated GitHub repositories, hands-on mini projects, and YouTube tutorials.
3. **Strict Fallback Guarantee:** If upstream LLMs fail or output malformed data, an internal deterministic generator delivers a fully validated 8-week curriculum.

---

### 📈 **Agent 3 — Live Labor Market Intelligence Agent**
> **Endpoint**: `GET /market/trends` · **Protocol**: REST · **Rate Limit**: 2 searches / 24 hours (24h cooldown)

**How It Works:**
1. **Live DuckDuckGo Scraping:** Fetches real-time tech job postings, hiring volumes, and salary ranges.
2. **Salary Normalization:** Parses salary bands into localized percentiles (25th, 50th, 75th, 90th percentile) in USD ($) or INR (₹).
3. **Demand Heatmap:** Identifies top required languages, emerging frameworks, and declining legacy technologies.
4. **Deterministic Fallback:** Guarantees zero downtime by providing pre-calculated market benchmarks if external search engines throttle.

---

### 💼 **Agent 4 — Executive LinkedIn Recruiter Strategy**
> **Endpoint**: `POST /linkedin/optimize` · **Protocol**: REST · **Rate Limit**: 2 uses / 24 hours (24h cooldown)

**How It Works:**
1. **Recruiter Search Keyword Injection:** Positions top search terms inside the headline and summary for maximum recruiter discovery.
2. **Headline Formulas:** Produces 3 high-impact variants: Role-Focused, Achievement-Oriented, and Skill-Dense.
3. **STAR About Narrative:** Writes a compelling 3-paragraph summary connecting past accomplishments with future career trajectory.
4. **Top 5 Skill Endorsement Prioritization:** Identifies the precise skills to pin to the top of the profile.

### ⚡ **Structured Phase Progression**

Questions strictly progress through structured phases according to the selected mode:

#### 🎯 **Full Mock (`full_mock` — 6 Phases)**
1. **Phase 1: Project & Resume Deep-Dive** — Architecture of past systems and candidate ownership.
2. **Phase 2: CS & Domain Fundamentals** — Language runtimes, memory, concurrency, database indexing, networking.
3. **Phase 3: Applied Coding Challenge** — Algorithmic problem with concrete test cases and space/time trade-offs.
4. **Phase 4: High-Scale System Design** — Distributed architecture, sharding, replication, and CAP theorem trade-offs.
5. **Phase 5: Production Resiliency & Failure Debugging** — Cascading failures, circuit breakers, dead-letter queues.
6. **Phase 6: Leadership & Company Culture Fit** — Technical disagreements, mentorship, code quality standards.

#### ⚡ **Quick Drill (`quick_drill` — 4 Phases)**
1. **Phase 1: Background & Architecture**
2. **Phase 2: Fundamentals & Trade-offs**
3. **Phase 3: High-Scale Bottlenecks**
4. **Phase 4: Operational Resiliency**

#### 🧠 **Topic Drills (`topic_drill` — 4 Targeted Phases per Domain)**
- **DSA & Coding**: Complexity & Data Structures → Advanced Traversal/DP → Scale Bottlenecks → Space/Time Optimization.
- **System Design (HLD/LLD)**: SLA Scoping → High-Level Architecture → Sharding/Caching → Production Failover.

## 🛡️ **6. Fault-Tolerant LLM Engine & Observability**

### 🔄 **Multi-LLM Provider Failover Architecture**

```text
 ┌────────────────────────────────────────────────────────┐
 │                   API REQUEST INGESTION                │
 └───────────────────────────┬────────────────────────────┘
                             │
                             ▼

 └───────────────────────────┬────────────────────────────┘
                             │
            ┌────────────────┴────────────────┐
            │ [Success]                       │ [Timeout / 429 / 5xx]
            ▼                                 ▼
   ┌─────────────────┐              ┌────────────────────────┐
   │ Stream Response │              │  CIRCUIT BREAKER ACTIV │
   └─────────────────┘              └───────────┬────────────┘
                                                │
                                                ▼
                                    ┌────────────────────────┐
                                    │  AUTOMATIC FAILOVER:   │
                                    │      OPENROUTER        │
                                    │ Models: llama-3.3-70b, │
                                    │ mistral-small-3.1,     │
                                    │ qwen-2.5-72b           │

                                                ▼

                                    └────────────────────────┘
```

- **Groq LPU (Primary):** Blazing fast inference (~600 tokens/sec) providing instant conversational turns.
- **OpenRouter (Failover):** Multi-model automatic fallback with exponential backoff if Groq encounters rate limits or upstream maintenance.
- *(Gemini and Nvidia dependencies have been cleanly decommissioned).*

### 📊 **Production Observability & Monitoring**
- **Prometheus Metrics (`/metrics`):** Exports request counts, latency histograms (`app_http_request_duration_seconds`), agent call counters (`ai_agent_calls_total`), and active interview sessions (`active_interviews`).
- **Sentry Crash Reporting:** Full exception capture with user ID, role, and endpoint context tags.
- **Diagnostic Health Endpoint (`/api/health`):** Validates database connections, LLM API keys, and memory health.
- **Admin Observability Dashboard (`/dashboard/admin/observability`):** Real-time web UI displaying request rates, error logs, and system memory stats.

## 🛠️ **9. Complete Tech Stack**

- **FastAPI (Python 3.11+)**: High-performance asynchronous API framework.

- **ChromaDB**: In-memory vector database powering ATS standard embeddings.
- **Edge-TTS**: Async Microsoft Edge neural text-to-speech engine.
- **SlowAPI & Redis**: Distributed token-bucket rate limiting and feature cooldowns.
- **Prometheus Client & Sentry SDK**: Real-time observability and crash tracing.

### ⚛️ **Frontend Core**
- **Next.js 14 (App Router)**: React framework with hybrid SSR and client-side streaming.
- **TypeScript**: Strict type checking with 0 compilation errors (`npx tsc --noEmit`).
- **Monaco Editor (`@monaco-editor/react`)**: In-browser VS Code editing sandbox.
- **Tailwind CSS & Lucide Icons**: Responsive layout with dark-mode glassmorphism aesthetics.
- **Lenis Smooth Scroll**: Inertial wheel scrolling with `data-lenis-prevent` boundaries.

<a id="local-setup-guide"></a>
## 🚀 **12. 5-Minute Local Setup Guide**

### 1️⃣ **Clone the Repository**
```bash
git clone https://github.com/Anil-Pradhan-web/ai-career-mentor.git
cd ai-career-mentor
```

### 2️⃣ **Configure Backend (`backend/.env`)**
```bash
cd backend
cp .env.example .env
```
Fill in the required keys:
```env
# Application
APP_ENV=development
DEBUG=True
SECRET_KEY=your_super_secret_jwt_key_here

# Database
DATABASE_URL=sqlite:///./dev.db

# LLM Providers (Groq Primary + OpenRouter Failover)
LLM_PROVIDER=groq
GROQ_API_KEY=gsk_your_groq_api_key_here
GROQ_MODEL=llama-3.3-70b-versatile
OPENROUTER_API_KEY=sk-or-your_openrouter_api_key_here
OPENROUTER_MODEL=meta-llama/llama-3.3-70b-instruct:free

# Auth
GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com

# Observability (Optional)
SENTRY_DSN=
```

Install dependencies & launch backend:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Swagger UI will be live at `http://localhost:8000/docs`.

### 3️⃣ **Configure Frontend (`frontend/.env.local`)**
```bash
cd ../frontend
cp .env.example .env.local
```
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com
```

Install dependencies & run dev server:
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.
