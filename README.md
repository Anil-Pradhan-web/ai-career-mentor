## 🎯 What is AI Career Mentor?

**AI Career Mentor** is a production-grade, full-stack career coaching platform that takes developers and students from career confusion to a concrete execution plan — all in one polished dashboard.

Most developers spend months wondering:

| ❓ Question | ✅ What We Do |
|---|---|
| 📚 *What should I learn next?* | 8-week personalized roadmap with curated resources |

| 🔎 *Which skills are in demand?* | Role + location + seniority-aware market intelligence |
| 🧾 *Why isn't my resume converting?* | ATS scoring with keyword, verb, and format breakdown |

> 🧑‍💻 **Solo-built** — backend, frontend, agent orchestration, Google OAuth, RAG, Docker, CI/CD, and production infrastructure, all by one developer.

### 🔄 Request Lifecycle — Full Career Analysis

```
  Step 1  →  User uploads resume PDF; target role + location sent
  Step 2  →  Rate limit check + SHA-256 cache lookup
  Step 3  →  Resume node runs: deterministic ATS + LLM enhancement
  Step 4  →  Market + LinkedIn nodes fan out in parallel
  Step 5  →  Roadmap node aggregates skill gaps + trends + LinkedIn data
  Step 6  →  Pydantic validation / repair layer catches malformed output
  Step 7  →  Result cached, usage incremented, activity logged
```

## 🧠 The 5 AI Workflows

| # | Workflow | What it does | Implementation |
|---|----------|--------------|----------------|
| 1️⃣ | **Resume Analyst** | Extracts skills, gaps, strengths, experience, ATS score | Deterministic ATS engine + LLM polish + Pydantic validation |
| 2️⃣ | **Market Researcher** | Salary, hiring, trend, company, and skill-demand insights | Market service + search APIs + LLM summary |
| 3️⃣ | **Career Coach / Roadmap** | 8-week role-specific execution plan | LangGraph aggregation + batched LLM calls + RAG enrichment |
| 4️⃣ | **LinkedIn Reviewer** | Profile positioning for recruiter search | Standalone optimizer + full-analysis node |
| 5️⃣ | **Mock Interviewer** | Real-time adaptive interview sessions | FastAPI WebSocket + direct model streaming + persisted history |

> The full-analysis workflow is powered by a **LangGraph static DAG** with parallel fan-out/fan-in, orchestrating specialized sub-agents with strict output parsing and validation.

## 🚀 Local Setup

### Prerequisites

- 🐍 Python **3.11+**
- 🟢 Node.js **18+** / npm
- 🔑 Groq, NVIDIA, or Google Gemini API key
- 🔐 Google OAuth Client ID
- 🔧 Optional: Redis, Serper, Tavily, Docker

### 1. Clone the Repository

```bash
git clone https://github.com/Anil-Pradhan-web/ai-career-mentor.git
cd ai-career-mentor
```

### 2. Backend Setup

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
```

Update `backend/.env`:

```env
# ── LLM Configuration ──────────────────────────────────────────
LLM_PROVIDER=groq
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=llama-3.3-70b-versatile
NVIDIA_API_KEY=your_nvidia_nim_key_here
NVIDIA_MODEL=meta/llama-3.3-70b-instruct
GOOGLE_API_KEY=your_google_api_key_here
GOOGLE_MODEL=gemini-2.5-flash

# ── Search APIs ────────────────────────────────────────────────
SERPER_API_KEY=your_serper_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here

# ── Database ───────────────────────────────────────────────────
DATABASE_URL=sqlite:///./dev.db

# ── Auth ───────────────────────────────────────────────────────
SECRET_KEY=your_super_secret_jwt_key_here
ACCESS_TOKEN_EXPIRE_MINUTES=60
REFRESH_TOKEN_EXPIRE_DAYS=30
GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com

# ── Redis / App ────────────────────────────────────────────────
REDIS_URL=redis://localhost:6379/0
APP_ENV=development
CORS_ORIGINS=http://localhost:3000
```

Start the backend:

```bash
uvicorn app.main:app --reload
```

| Endpoint | URL |
|---|---|
| API Root | `http://localhost:8000` |
| Swagger Docs | `http://localhost:8000/docs` |
| Health Check | `http://localhost:8000/health` |

### 3. Frontend Setup

```bash
cd frontend
npm install
```

Create `frontend/.env.local`:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com
```

```bash
npm run dev
# Runs at http://localhost:3000
```

### 4. Docker Setup

```bash
# Development stack
docker compose up --build

# Production override
docker compose -f docker-compose.yml -f docker-compose.prod.yml up --build
```

## 🔄 CI/CD Pipeline & Hardening

### GitHub Actions

| Workflow | Trigger | Steps |
|---|---|---|
| **CI** | Every push | Frontend: `npm ci` → lint → build · Backend: install → pytest → pip-audit |
| **Backend Deploy** | Push to `main` (backend files) | Render deploy hook |
| **Docker Publish** | Push to `main` | Build + publish backend + frontend images to GHCR |

### Production Hardening Checklist

```
✅  CORS allow-listing via CORS_ORIGINS (no wildcards in production)
✅  Production rejects SQLite, default secrets, missing search API keys
✅  Postgres pool: pool_pre_ping + pool_recycle + small pool_size
✅  Redis-aware rate limiting (memory fallback in dev)
✅  WebSocket cleanup guards for disconnected interview sessions
✅  SHA-256 keyed Redis cache for full-analysis results
✅  Pydantic validation/repair loops catch malformed LLM outputs
✅  Container-ready: Dockerfile + Docker Compose for local + production
```
