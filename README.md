## 🧭 **What is AI Career Mentor?**

**AI Career Mentor** is a **production-grade, full-stack career coaching platform** 🤖 that transforms career confusion into concrete execution plans. It orchestrates **6 specialized AI workflows** through a unified dashboard with **real-time streaming**, **voice conversations**, and **intelligent fallback systems**.

### 🎯 **The Problem It Solves**

> Developers waste **months** figuring out career transitions — what skills to learn, which companies to target, how to optimize their profiles, and how to prepare for interviews. AI Career Mentor **automates all of this** in minutes.

### 🚀 **The 6 AI Workflows**

| # | 🚦 Workflow | 🚇 Transport | ⚙️ Engine | 🎯 What It Does |
|---|-------------|-------------|-----------|-----------------|
| 1 | **📄 Resume Intelligence** | `REST` | Deterministic ATS + LLM Hybrid | ATS scoring, skill extraction, gap analysis, experience parsing |
| 2 | **🗺️ Career Roadmap Builder** | `REST` | LangGraph + RAG + Google Gemini | 8-week gamified learning plans with curated resources |
| 3 | **📈 Market Explorer** | `REST` | Tavily/Serper + Groq LLM | Real-time salary data, hiring trends, company intelligence |
| 4 | **🔗 LinkedIn Optimizer** | `REST` | Groq/NVIDIA + Programmatic Fallback | Profile optimization with ATS keyword injection, recruiter trends |
| 5 | **🎤 Mock Interview Engine** | `🔌 WebSocket` | 7-Phase FSM + NVIDIA NIM | Adaptive coding interviews with TTS audio and scoring |
| 6 | **🎙️ Anya Voice Coach** | `🔌 WebSocket` | Gemini Live Multimodal API | Real-time bidirectional Hinglish voice career coaching |

### 🌟 **What Makes It Special**

| Feature | Description |
|---------|-------------|
| ⚡ **Parallel DAG Orchestration** | LangGraph fans out `Resume + Market` simultaneously, then fans in to `LinkedIn + Roadmap` — reducing total latency by **~60%** |
| 🛡️ **Multi-Layer Fallback** | Every workflow has **2-3 LLM fallback providers** + **deterministic/programmatic fallback** — zero single point of failure |
| 🧠 **Hybrid AI Architecture** | **Rule-based engines** (ATS scoring, experience parsing) + **LLM enrichment** (market formatting, strategy generation) = accuracy + intelligence |
| 🔌 **Real-Time Communication** | WebSocket for mock interviews (FSM-driven) + Voice coach (full-duplex audio), SSE for career analysis streaming |
| 🗃️ **RAG-Enriched Resources** | ChromaDB vector store + keyword fallback + URL validation engine for high-quality learning resources |
| 🧪 **102 Passing Tests** | Full test coverage across agent registry, validation schemas, ATS engine, market service, and more |

### 🧭 **Agent Registry Architecture**

The **Agent Registry** (`registry.py`) is a production-hardened LLM caller with:

```mermaid
flowchart TD
    CALL["call_llm()"]
    
    CB{"⚡ Circuit Breaker<br/>OPEN?"}
    
    DISP["_dispatch()<br/>Route to provider"]
    
    RETRY{"🔄 Retry<br/>attempt < 3?"}
    
    FALLBACK{"➡️ Fallback<br/>Provider?"}
    
    PARSE["_parse_structured()<br/>Pydantic validation"]
    
    CALL --> CB
    
    CB -->|"🚫 Open (60s cooldown)"| FALLBACK
    CB -->|"✅ Closed"| DISP
    
    DISP -->|"✅ Success"| PARSE
    DISP -->|"❌ Error"| RETRY
    
    RETRY -->|"Yes"| FALLBACK
    RETRY -->|"No (exponential backoff)"| DISP
    
    FALLBACK -->|"Next provider"| CB
    FALLBACK -->|"Chain exhausted"| RET_NONE["Return None"]
    
    PARSE --> VAL["Pydantic<br/>Validation"]
    VAL -->|"✅ Valid"| RESET["Reset Circuit Breaker"]
    VAL -->|"❌ Parse Error"| RETRY
    
    RESET --> RET["Return dict"]
    
    style CALL fill:#818cf8,color:#fff
    style RET fill:#34d399,color:#fff
    style RET_NONE fill:#ef4444,color:#fff
```

### 🛡️ **Circuit Breaker Details**

| Parameter | Value |
|-----------|-------|

| **Cooldown Duration** | 60 seconds |
| **Max Retries** | 3 (with exponential backoff: 2^attempt seconds) |
| **Scope** | Per-provider singleton |

## 🚀 **Local Setup Guide**

### ✅ **Prerequisites**

| Tool | Version | Purpose |
|------|---------|---------|
| 🐍 Python | 3.11+ | Backend runtime |
| 🟢 Node.js | 20+ | Frontend runtime |
| 📦 Redis | Latest (optional) | Rate limiting (falls back to in-memory) |

### 📥 **Step 1: Clone & Set Up Backend**

```bash
# Clone the repository
git clone https://github.com/Anil-Pradhan-web/ai-career-mentor.git
cd ai-career-mentor/backend

# Create virtual environment
python -m venv venv

# Activate it
# Windows:
venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Create environment file
cp .env.example .env
```

### 🔑 **Step 2: Configure Environment Variables**

Edit `backend/.env`:

```env
# ⚡ LLM Provider (groq is FREE — no credit card!)
LLM_PROVIDER=groq

# 🆓 Get from https://console.groq.com → API Keys
GROQ_API_KEY=gsk_your_key_here

# 🔵 Optional — Get from https://aistudio.google.com
GOOGLE_API_KEY=your_gemini_key

# 🟢 Optional — NVIDIA NIM
NVIDIA_API_KEY=nvapi-your_key

# 🗄️ Database (SQLite for dev, PostgreSQL for prod)
DATABASE_URL=sqlite:///./dev.db

# 🔐 JWT Secret (change in production!)
SECRET_KEY=your-secret-key-change-this

# 🌐 Google OAuth (for Google Login)
GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
```

### 🏃 **Step 3: Run Backend**

```bash
# Run database migrations
alembic upgrade head

# Start FastAPI server
uvicorn app.main:app --reload
```

Backend is now live at:
- 🌍 **API**: http://localhost:8000
- 📘 **Swagger UI**: http://localhost:8000/docs
- 📋 **ReDoc**: http://localhost:8000/redoc

```bash
cd ../frontend

# Install dependencies

# Create environment file
# frontend/.env.local:
cat > .env.local << EOL
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
EOL

```

Frontend is now live at: **http://localhost:3000** 🌟

### 🛡️ **Production Hardening**

| Measure | Description |
|---------|-------------|
| **🔄 Auto-Deploy** | Backend (Render) + Frontend (Vercel) redeploy on `main` pushes |
| **🛡️ OOM Prevention** | Auto-disables ONNX embedding models in 512MB RAM environments |
| **⏰ 48-Hour Locks** | Premium features (interview, full_analysis) protected via Redis TTL |
| **📝 Safe Logging** | Prevents KeyError crashes in JSON-heavy logging payloads |
| **🚫 Production Guards** | Blocks SQLite and default secrets in production environment |
| **✅ Pipeline Integrity** | ESLint + Build + 102 Tests + Security Audit = Merge Gate |
